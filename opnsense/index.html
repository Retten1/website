Project: OPNsense Deployment

Researching and deploying a secure, open-source firewall solution in my local homelab environment.

Project description

For this project, I am researching and implementing OPNsense on my home network. The goal is to segment network traffic using VLANs, configure strict firewall rules, and ensure secure network management.

What I've accomplished so far:

  • Installation and Basic Configuration of OPNsense on Dedicated Hardware / Proxmox.
  • Configuration of WAN and LAN interfaces.
  • Research on firewall rulesets and network security.
  • Segmenting my network with VLANs.
  • Using internal OSPF with other routers.
  • Researching BGP and AS Numbers
